# 泥潭7 FluffOS 最新版 ([v2025.1205.0](https://github.com/fluffos/fluffos/releases/tag/v2025.1205.0))

泥潭7為lonely開發的經典MUD，此版本是 FluffOS 作者的分叉，主要是作了以下更改：
* 原LIB需使用 FluffOS v2019，此版將是相容於最新版的 FluffOS
* 原LIB是UTF8簡體中文，此版是繁體中文

### 使用說明

請使用 [Fluffos v2025.1205.0](https://github.com/fluffos/fluffos/releases/tag/v2025.1205.0) 驅動運行

    driver config.ini

遊戲端口 5555 為GBK，6666 為 utf-8，8888 為WEB訪問。

註冊ID為 `mudren` 或 `lonely` 的賬號為遊戲管理員。
