# 泥潭7 FluffOS v2019版

泥潭7為lonely開發的經典MUD，原版LIB需要使用專版驅動，本LIB升級為utf8版並修改為直接使用FluffOS v2019官方版驅動。

>請注意：本LIB的代碼BUG未完全修正，如需使用本LIB請自己根據日誌修正。

Updated the files to work with FluffOS following the guidelines in the following, https://forum.fluffos.info/t/common-lpc-migration-issues-v2019/1341

### 使用說明

請使用 fluffos v2019 驅動運行

    driver config.ini

遊戲端口 5555 為GBK，6666 為 utf-8，8888 為WEB訪問。

註冊ID為 `mudren` 或 `lonely` 的賬號為遊戲管理員。

如有問題，請在此留言交流：https://bbs.mud.ren/threads/97
